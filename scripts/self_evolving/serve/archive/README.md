# Archived server launchers

Server launchers tied to specific past experiments (fixed model, server and stage), moved here
on 2026-11-21. The shared servers (embedding, TRAPI proxy, generic gen server, vLLM/chat,
summarizer) are still in `serve/`.

The runs that used these are in `../../train/archive/`, which explains how to run them again
(short version: move them back with `git mv`, or check out commit `b01884ee`).
